      🔓 Unlock puzzle review — free, 1 minute, step by step

      The game tracking above needs no login at all — it is all public. But your wrong puzzles and their review schedule are private on Lichess — they need a read-only token from your own account:

      When Lichess shows the scope list, tick only puzzle:read: no other box adds anything here, the rest would only give the token powers it doesn't need (playing moves, messages).

      1. Open lichess.org/account/oauth/token and sign in if asked.
      2. Write any description, e.g. Obsidian Play review.
      3. Tick only the scope Read puzzle activity (puzzle:read). Nothing else.
      4. Tap Generate, copy the token (starts with lip_) and paste it here. It can only read puzzle activity — it cannot play, chat or change your account, and you can delete it anytime on that same page.

      Enter it once — this browser remembers it. After a successful unlock, the token is saved in this browser on this phone (local storage) and reconnected automatically every time you open this page's website link again — no Muse sign-in, no re-pasting. It is only ever sent to lichess.org, never to any other server, and Disconnect below forgets it instantly. Pasting is cleaned up automatically (stray spaces or line breaks are removed), and Lichess itself confirms the token before anything loads.

      Your review progress stays on this phone even if you disconnect. Disconnecting forgets the token only — which puzzles are due, and when, stays saved in this browser, so reconnecting later picks up exactly where you left off.

      Data comes live from the official Lichess API — lichess.org/api · Public stats: /api/user & rating history · Games (public): /api/user/{user}/perf & /api/user/{user}/activity · Private puzzle review (with your token): /api/puzzle/activity · Auto-refresh every 20s (Lichess has no push feed, so ~20s is true real-time here) · Bismillah — one game at a time.
